# jamesfryman.com

Personal site for James Fryman — built with [Hugo](https://gohugo.io/) and a custom terminal-themed design.

## Local Development

```bash
hugo server -D
```

Then open http://localhost:1313

## Deployment

Push to `main` — GitHub Actions will build and deploy to GitHub Pages automatically.

## Customizing

- **Content**: Edit `themes/terminal/layouts/index.html` for homepage sections
- **Styling**: Edit `static/css/style.css`
- **Config**: `hugo.toml`
